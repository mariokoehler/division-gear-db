Gear Set Bonus Finder

Tom Clancy's The Division 2 — pick one or more bonus types to see every brand / gear set / named item / exotic item that grants them.

Data notes

All 64 Brand Sets and Gear Sets, 62 Named Items, and 30 Exotic Items were extracted directly from the game's own data files (Snowdrop engine .sdftoc/.sdfdata archives, via the community tool Hunter) and cross-checked against wiki data — this surfaced several brands/sets no community source had documented, and caught a few whose values had drifted since a balance patch. No known gaps remain in Brand/Gear Set coverage.

Named Items (gloves/kneepads/holsters/masks/chests/backpacks with a unique name, like Deathgrips or Turmoil) carry a guaranteed, always-maxed "Fixed" attribute (Gloves/Holster/ Kneepads/Mask only — Backpacks and Chests don't roll one at all, their named identity is purely a unique talent instead, a real game-design fact rather than a data gap) and/or a unique talent. Three Fixed attributes (Reduced Threat, Damage to Targets Out of Cover, Melee Damage) are exclusive to their one named item — no Brand or Gear Set grants them. One gap remains: Ongoing Directive's backpack companion talent has no .mtalent file in any export used so far.

Exotic Items (Catharsis, Memento, etc. — the small pool of gear whose talent never appears on any Brand/Gear Set/Named Item) usually carry exactly two guaranteed bonus types (shown as "Fixed") plus their talent; unlike a Named Item's Fixed attribute, the actual rolled value is always random, so only the stat type is shown. Investor is a confirmed exception — its own talent says its Core and all bonus slots are fully random by design, shown with an explicit "confirmed fully random" note. Acosta's Go Bag is the only item with two simultaneously-active talents ("One in Hand..." and "...Two in the Bag"), both shown on its card. Acosta's Kneepads is missing both bonus types in this export (flagged, not guessed); a few unreleased/placeholder items are deliberately excluded.

Core attribute (Red/Offensive, Blue/Defensive, Yellow/Utility — a real property of every item, never optional in-game) is shown for every Named Item, Exotic Item, and Gear Set piece. Backpack/Chest named items don't carry their own Core in their dedicated config (talent only, same reason as their missing Fixed attribute) — it's inherited instead from the regular civilian-brand piece the named item is based on. A handful of exotic Backpacks (Memento, Harrier Pride, Ninja Bike Messenger Bag) genuinely support all three Cores simultaneously rather than just one.

Gear Sets show the union of every Core found across their 6 pieces: 24 of 27 sets share one Core across all pieces, while Refactor and System Corruption each genuinely split two different Cores by slot, and Core Strength is deliberately flexible — its own 4-piece talent text says "All pieces except the Backpack feature random Cores". Use the Red/Blue/Yellow filter above the chips to see this — Brand entries drop out entirely, since a civilian brand spans many different items with no single fixed Core.

Potential bonuses (conditional) — many talents also grant a real bonus attribute under some condition (e.g. "+15% Weapon Damage while in cover"), interpreted by hand and shown wherever they apply: on an Exotic Item's own card, or as a standalone "Talent" result card for a talent not tied to any one item. These rows highlight like a guaranteed bonus when they match your selected chip(s) but stay visually distinct (cyan, "conditional") since they're never guaranteed just by equipping the item. Only talents confirmed live — in the game's own random-roll pool, or a specific item's own preset — are shown here or in the Talent Browser; a handful found in the game's files matched neither and are excluded as legacy/cut content.

About the Talent Browser

Every weapon and gear Talent datamined from the game's own files, not just the ones already referenced by a specific Brand/Gear Set/Named/Exotic Item elsewhere in this tool. Gear Set 4-piece/companion talents are excluded here since they already have their own card in the Attribute Finder tab; a talent that's also a Named/Exotic Item's unique talent intentionally appears in both places.

Gear slot (Chest/Backpack — the only two slots a non-Exotic item can roll a Talent on at all; Mask/Gloves/Holster/Kneepads only roll attributes) is read from the game's own random-roll talent pool data, not the talent's filename, which is frequently wrong or missing entirely. A small number of talents genuinely roll on either Chest or Backpack and show both. A Chest/Backpack talent absent from that pool and not any Named Item's own preset talent is excluded entirely as legacy/cut data rather than shown as if obtainable. Weapon type and Exotic item categorization is still filename/cross-reference-based rather than pool-verified the same way — see `CLAUDE.md`'s "All Talents" section for what's been checked.

"Legacy / Removed" is every talent with no recognizable slot or weapon-type token at all. Unlike the Chest/Backpack bucket above, these haven't yet been checked against the game's own weapon-side talent pools (this tool has never parsed weapon item files) — treat entries here as likely-but-not-verified legacy rather than a confirmed claim.

Numeric values in descriptions are filled into the game's own text template using a best-effort heuristic (guessing percent vs. a flat number from the value's size) that hasn't been manually reviewed per-talent here — an occasional value (e.g. a short buff duration) may be mis-formatted as a percentage instead of seconds.

Data extracted directly from the game's Snowdrop engine archives (via the Hunter extraction tool) and cross-checked against mx-division-builds and The Division Wiki. 64 brands/gear sets total (37 Brand Sets, 27 Gear Sets), plus 62 Named Items and 30 Exotic Items. Piece count = number of items of that brand/set equipped to unlock the bonus; "Fixed" = a named item's guaranteed, always-maxed bonus attribute. See the data notes above for details. The Talent Browser tab covers the full weapon/gear Talent catalog beyond just these entries.
