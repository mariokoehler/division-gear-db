Gear Set Bonus Finder

Tom Clancy's The Division 2 — pick one or more bonus types to see every brand / gear set / named item / exotic item that grants them.

Data notes

All 64 Brand Sets and Gear Sets below were extracted directly from the game's own data files (Snowdrop engine .sdftoc/.sdfdata archives, via the community tool Hunter), then cross-checked against wiki data. This resolved every brand/gear set that was previously missing from community sources, caught a few brands whose bonus values had changed in a balance patch since the wiki was last updated, and (with an in-game assist for two final details — Unit Alloys' 1-piece stat and Refactor's 4-piece talent tooltip) reached full coverage with no known gaps.

Named Items (62 of them — gloves/kneepads/holsters/masks/chests/backpacks with a unique name, like Deathgrips or Turmoil) were datamined the same way, from each item's own .mitem file plus its loot-generation config. Gloves/Holster/Kneepads/Mask named items always carry one or two guaranteed, always-maxed bonus attributes (shown as "Fixed") — three of those (Reduced Threat, Damage to Targets Out of Cover, Melee Damage) don't appear on any Brand Set or Gear Set, i.e. they're exclusive to that one named item. Backpacks and Chest pieces don't roll a fixed attribute at all — their named identity is purely a unique talent instead. Every named item with a talent now shows its full name and description; the only remaining gap is Ongoing Directive's backpack companion talent, whose .mtalent file genuinely doesn't exist in any export used so far.

Exotic Items (28 of them — the small pool of gear pieces with their own always-unique talent, like Catharsis or Deathgrips-tier gear but at Exotic quality) always carry exactly two guaranteed bonus types (shown as "Fixed") plus their unique talent — unlike a named item's Fixed attribute, an exotic's actual rolled value is always random, so only the stat type is shown, never a number. One item (Acosta's Kneepads) is missing both bonus types from this export; a small number of unreleased/placeholder exotics found in the game's own data (an item literally named "TBD", one with a dead NULLREFERENCE config, and Investor — a real item confirmed by the user to be intentionally fully-random rather than following the "always X and Y" pattern) are deliberately excluded rather than shown incomplete or fabricated.

Core attribute (Red/Offensive, Blue/Defensive, Yellow/Utility) — a real property of every item, never optional in-game — is shown for all 28 Exotic Items and all 62 Named Items. Backpack/Chest named items don't carry their own Core in their dedicated config (talent only, same reason they have no Fixed attribute either); it's instead resolved from the regular, non-named civilian-brand piece the named item's model and identity is drawn from, confirmed correct in-game by the user for Chainkiller (Red) and Closer (Blue). Two items (Force Multiplier, Door-Kicker's Knock) can't be resolved this way even so — their underlying base piece itself rolls a random core in this data — so those two are confirmed instead from the user's own in-game knowledge (Yellow and Red respectively) rather than datamined. A handful of exotic Backpacks (confirmed by the user for Memento, and assumed the same for the two structurally-identical Harrier Pride and Ninja Bike Messenger Bag) genuinely support all three cores simultaneously rather than just one.

All 27 Gear Sets also show a Core attribute — each set's 6 pieces are ordinary items with their own Core just like any Named/Exotic Item, confirmed correct in-game by the user for Striker's Battlegear (Red) and Foundry Bulwark (Blue). 24 of 27 sets have one single Core shared by every piece; the badge shows every distinct Core found across a set's pieces, so 3 real exceptions read correctly too: Refactor and System Corruption each genuinely split two different Cores across their pieces (confirmed by each piece's own explicit, non-random preset — not a data gap), and Core Strength is a deliberately flexible set — its own 4-piece talent text says so directly ("All pieces except the Backpack feature random Cores"), and its Backpack alone spans all three, the same "flexible core" pattern seen on a few exotic Backpacks. Use the Red/Blue/Yellow filter above the bonus-type chips to see every Brand entry drop out (a civilian brand spans many different items with no single fixed Core) while Gear Sets, Named Items, and Exotic Items filter down to just that color.

About the Talent Browser

Every weapon and gear Talent datamined from the game's own files, not just the ones already referenced by a specific Brand/Gear Set/Named/Exotic Item elsewhere in this tool — including the large "universal" pool droppable on any weapon or any gear piece regardless of slot. Gear Set 4-piece/companion talents are deliberately excluded here since they're already shown on their own Gear Set's card in the Attribute Finder tab; a talent that's also a Named/Exotic Item's unique talent intentionally does still appear in both places.

Gear slot (Chest/Backpack — the only two slots a non-Exotic item can roll a Talent on at all, confirmed by the user; Mask/Gloves/Holster/Kneepads only roll attributes) is read from the game's own random-roll talent pool data, not the talent's filename — the filename is frequently wrong or missing entirely (e.g. Headhunter, a Chest-only talent, is filed as `warlock_talent_headshot_kills_increase_next_weapon_hit` with no slot token at all; Tag Team, also Chest-only, is filed as `talent_mask_hits_reduce_cooldown`). A small number of talents genuinely roll on either Chest or Backpack and show both. Weapon type and Exotic item categorization is still filename/cross-reference-based rather than pool-verified the same way — see `CLAUDE.md`'s "All Talents" section for exactly what's been checked.

Numeric values in descriptions are filled into the game's own text template using the same best-effort heuristic already used elsewhere in this tool for Gear Set talents (guessing percent vs. a flat number from the value's size) — for the ~357 talents here that heuristic hasn't been manually reviewed per-talent, so an occasional value (e.g. a short buff duration) may be mis-formatted as a percentage instead of seconds.

Data extracted directly from the game's Snowdrop engine archives (via the Hunter extraction tool) and cross-checked against mx-division-builds and The Division Wiki. 64 brands/gear sets total (37 Brand Sets, 27 Gear Sets), plus 62 Named Items and 28 Exotic Items. Piece count = number of items of that brand/set equipped to unlock the bonus; "Fixed" = a named item's guaranteed, always-maxed bonus attribute. See the data notes above for details. The Talent Browser tab covers the full weapon/gear Talent catalog beyond just these entries.
