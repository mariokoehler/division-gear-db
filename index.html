Gear Set Bonus Finder

Tom Clancy's The Division 2 — pick one or more bonus types to see every brand / gear set / named item that grants them.

Data notes

All 64 Brand Sets and Gear Sets below were extracted directly from the game's own data files (Snowdrop engine .sdftoc/.sdfdata archives, via the community tool Hunter), then cross-checked against wiki data. This resolved every brand/gear set that was previously missing from community sources, caught a few brands whose bonus values had changed in a balance patch since the wiki was last updated, and (with an in-game assist for two final details — Unit Alloys' 1-piece stat and Refactor's 4-piece talent tooltip) reached full coverage with no known gaps.

Named Items (62 of them — gloves/kneepads/holsters/masks/chests/backpacks with a unique name, like Deathgrips or Turmoil) were datamined the same way, from each item's own .mitem file plus its loot-generation config. Gloves/Holster/Kneepads/Mask named items always carry one or two guaranteed, always-maxed bonus attributes (shown as "Fixed") — three of those (Reduced Threat, Damage to Targets Out of Cover, Melee Damage) don't appear on any Brand Set or Gear Set, i.e. they're exclusive to that one named item. Backpacks and Chest pieces don't roll a fixed attribute at all — their named identity is purely a unique talent instead. Every named item's talent shows its own "Talent" row with a name, whether resolved or not — for 35 of them that talent's own .mtalent file was missing from this export, so only the name is flagged "not yet catalogued" rather than shown, even though we know the item has one.
